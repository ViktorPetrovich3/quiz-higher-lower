# quiz-higher-lower
Веб-приложение викторина на выбор наиболее популярного варианта ответа

Инструкция по запуску и отключению сервера: 
    1. Ввести в терминале npm start
    2. Открыть веб-прилоение в браузере по ссылке
    3. Для отлючения сервера нужно нажать комбинацию клавишь Ctr + C в терминале
